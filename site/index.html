    需要什么

    • Windows 10 或 11（64 位）
    • Minecraft {{minecraft}}，NeoForge {{loaderMin}} 及以上，Java {{java}}（用 HMCL、PCL 等启动器装好）
    • 一个 Agent，在本机装好并登录：Claude Code、Codex CLI 或 DeepSeek Harness

    怎么用

    1. 下载并运行安装包。安装包没有代码签名，Windows 可能提示“已保护你的电脑”，点“更多信息”，再点“仍要运行”。
    2. 从开始菜单或桌面打开 mcbot，浏览器里会打开它的设置页（只在本机）。
    3. 在「插件」页选你的游戏，安装核心模组和想用的插件，然后启动游戏。
    4. 进入世界。单人世界要先按 Esc 选「对局域网开放」。
    5. 在「配置」页选 Agent 和角色，点启动托管，然后在游戏里叫它的名字。

    登录信息、记忆和日志都留在你的电脑上。有新版本时，打开 mcbot 会提示更新。
