# 建筑设计参考

blueprints 的 guide 动作给出这份参考：不带 topic 时给前面几节和风格列表，带 topic 时给那个风格。设计说明见仓库 docs/building_design.md。

## 流程

1. 先和玩家说好：盖什么、多大、在哪、正门朝哪、什么风格；看看地面平不平。
2. 用零件写设计（下一节），blueprints save 存起来；同一个设计改了就另存一个名字，玩家认可的版本留着。
3. blueprints render 画出来看：上面两张斜 45° 立体图，下面每层平面图，还有文字平面图。按最后一节的检查清单挑毛病，用 edit 改几处、或者改设计重新 save，再画。
4. 把图给玩家看（说清楚大小、材料），玩家同意再盖。
5. build 带 blueprint 先 dryRun 看缺什么料，备齐再盖。一次最多 4096 格，大房子分几次。

## 零件

build 和 blueprints save/render 都收 shapes（按顺序，后面的盖掉前面同一格）、blocks 和 palette。坐标是绝对坐标（save 后存成相对最小角）。

- palette：按用途起名字的材料表，比如 {"frame":"spruce_log","wall":"oak_planks","roof":"dark_oak_stairs"}；任何写方块的地方写 "@wall"，也可以加属性 "@frame[axis=x]"。换风格只要换材料表。
- fill／hollow／walls：from 到 to 的实心块、空心盒、四面墙。line：一条线，原木、柱子类会顺着线的方向放。
- box：一个体块。from/to 是外框，四周是 block 的墙；floor 填最底层里面，ceiling 填最顶层里面；frame 给了就在最底层和最顶层加一圈横梁、四角和每 pillarEvery 格加竖柱（原木自动朝向）。
- window：墙上的窗洞。from/to 在同一面墙上（朝南北的窗 z 相同，朝东西的 x 相同），facing 是窗朝外的方向，block 是玻璃。recess:true 玻璃往里退一格，窗洞更有深度；sill 是窗下面外侧的窗台（楼梯会倒放贴墙，台阶放上半）；trim 是窗四周一圈框。
- door：门洞，一格或两格宽（两格是双开门，铰链在外侧），facing 朝外，block 写门（spruce_door）。门上面那格自动空出来给门的上半，门洞再高的部分留空；trim 是门框。
- stairs：室内楼梯，facing 是往上走的方向，from/to 是第一级和最后一级（每往前一格升一格），宽度是另一个方向的范围；每级上面自动空出两格（会在上一层楼板上开出楼梯洞），support 给了就把每级下面填实。
- roof：屋顶。from/to 是屋顶最底一层：放在墙顶再上一层，长边两侧各宽出一格做屋檐，两端和墙齐平（山墙正好砌在端墙上）。style 是 gable（双坡，默认，两端是山墙，gableBlock 默认同材料的完整方块，"none" 不要山墙）或 hip（四坡，没有山墙）。pitch 1（默认）用楼梯，每格升一格；pitch 0.5 用台阶，每格升半格，屋顶平缓（日式、中式常用）。屋脊默认用台阶，ridgeBlock 可以换。

一个 13×9 的木屋（正门朝北）：

```json
{"palette":{"frame":"spruce_log","wall":"oak_planks","floor":"spruce_planks","roof":"dark_oak_stairs","glass":"glass_pane"},
 "shapes":[
  {"shape":"box","from":{"x":0,"y":0,"z":0},"to":{"x":12,"y":4,"z":8},"block":"@wall","frame":"@frame","floor":"@floor","pillarEvery":4},
  {"shape":"door","from":{"x":6,"y":1,"z":0},"to":{"x":6,"y":2,"z":0},"block":"spruce_door","facing":"north"},
  {"shape":"window","from":{"x":1,"y":2,"z":8},"to":{"x":3,"y":3,"z":8},"block":"@glass","facing":"south","recess":true,"sill":"spruce_stairs"},
  {"shape":"window","from":{"x":9,"y":2,"z":8},"to":{"x":11,"y":3,"z":8},"block":"@glass","facing":"south","recess":true,"sill":"spruce_stairs"},
  {"shape":"roof","from":{"x":0,"y":5,"z":-1},"to":{"x":12,"y":5,"z":9},"block":"@roof"}],
 "blocks":[{"x":6,"y":0,"z":-1,"block":"spruce_stairs[facing=south]"}]}
```

y=0 是地面上第一层：地板在 y=0，屋里能站的是 y=1～3，门口外面放一级楼梯上来。

## 通用手法

- 体块：先定 1～3 个长方体，一主一次；L 形、T 形、主屋加侧翼比一个方盒子好看。二层可以比一层外挑或内收一格。
- 比例：每层从地板到上一层楼板 4～5 格（屋里净高 3～4 格）；屋顶高度大约是立面的三分之一到一半；太长的墙用柱子或体块分段。
- 材料分工：地基（圆石、石砖，一两层）→ 墙（木板、陶瓦、羊毛、混凝土）→ 框架（原木柱、横梁）→ 屋顶（深色的楼梯或台阶）。主材大约六成、辅材三成、点缀一成，一栋 3～5 种主要方块；颜色深浅搭配，不要两种很冲的颜色硬碰。
- 质感：大面积的主材可以混 2～3 种相近的方块（石砖、裂纹石砖、苔石砖），看起来有年代感；混的时候成片、不要每格乱撒。
- 立体感：墙面不要完全平。柱子每 3～5 格一根、横梁压在楼层线上、窗洞内退一格、窗下有窗台、屋檐外挑一格，檐下可以倒放一排楼梯。
- 窗和门：窗成组、有节奏，上下层对齐；玻璃板比玻璃块细致。正门要显眼：门两边放灯或柱子，上面有雨棚或横梁，门口有台阶。
- 细节：活板门做百叶、窗台、桌面；栅栏做栏杆和支架；灯笼挂在檐下或立在柱子上；树叶做花槽和灌木；花、小路收尾。
- 室内：每个房间有光源；楼梯上面留两格；床、工作台、箱子靠墙。
- 生存模式：木头、石头、玻璃好拿；羊毛、混凝土、石英、下界材料要玩家准备，设计前问一句。复杂的屋顶（翘角、曲面）build 可能放不准，先用 roof 零件能盖出来的样子。

## 看图检查

- 比例：太扁、太高、屋顶太小？从远处看轮廓有没有主次。
- 平墙：有没有超过 5×5 一成不变的墙面。
- 窗：节奏乱不乱、上下对不对得齐、一面墙是不是没有窗。
- 颜色：是不是太杂，或者对比太硬。
- 屋顶：边缘和屋脊整不整齐，有没有漏洞，山墙有没有补上。
- 能不能住：门口能不能走进去，楼梯净空够不够，每层有没有灯。
- 文字平面图里 # 是墙、W 是窗、D 是门、/ 是楼梯，用来核对坐标。

## 风格：日式

初稿，按收集的投影（日式寺院、拉面馆、千与千寻小屋）整理，之后会补数据。
- 材料：深色木框架（深色橡木、云杉原木或去皮原木）、白墙（白色羊毛、白色混凝土、平滑石英、方解石）、深色瓦屋顶（深板岩瓦、深板岩砖、黑石的楼梯和台阶）、石砖地基。
- 形体：低矮宽大，屋顶占立面一半左右，出檐深（两格也常见）；屋顶用 pitch 0.5 的台阶，平缓。
- 细节：活板门做格栅窗和栏杆，灯笼挂檐下，樱花树叶、竹子、粉红花簇点缀；寺院用石砖、裂纹石砖、苔石砖混出旧石墙。

## 风格：乡村木屋

初稿，按小木屋第二弹、石屋_三、花园生存农舍整理。
- 材料：橡木或云杉原木框架、木板墙、圆石或石砖地基，屋顶用云杉或深色橡木楼梯，也有石砖楼梯。
- 形体：一到两层，双坡屋顶，主屋加侧翼或门廊。
- 细节：玻璃板窗配窗台，栅栏做门廊栏杆，灯笼和火把，树叶做花槽，屋外有小路、菜地、篱笆。

## 风格：石砖小屋

初稿，按小房屋第四弹整理。
- 材料：石砖墙、平滑石台阶和石砖台阶屋顶（pitch 0.5）、玻璃板、树叶点缀。
- 形体：方正，一层半，屋顶用台阶层层收上去。

## 风格：现代

初稿，按泳池小院别墅和以前做过的现代平顶别墅整理。
- 材料：白色混凝土或石英为主，浅灰、灰色混凝土分层，大面积玻璃板，白桦或橡木木色点缀，末地烛、海晶灯做灯。
- 形体：几个长方体错开叠放，平顶，屋顶边缘半砖收边；大窗、露台、泳池庭院。
- 搭配：深色要用有纹理的材料（深板岩、木头），不要纯黑和纯白硬碰。

## 风格：西部酒馆

初稿，按沙龙酒馆整理。
- 材料：多种木板拼墙（云杉、白桦、橡木），橡木原木柱，台阶和楼梯屋顶，玻璃板窗。
- 形体：临街立面高出屋顶的假门脸，门廊加栏杆，一层大厅。
- 细节：栅栏门、吧台用台阶和活板门、酿造台和炼药锅当摆设。
