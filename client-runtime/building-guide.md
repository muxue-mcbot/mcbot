# 建筑设计参考

blueprints 的 guide 动作给出这份参考：不带 topic 时给前面几节和风格列表，带 topic 时给那个风格。设计说明见仓库 docs/building_design.md。

## 流程

1. 先和玩家说好：盖什么、多大、在哪、正门朝哪、什么风格；看看地面平不平。
2. 用零件写设计（下一节），blueprints save 存起来；同一个设计改了就另存一个名字，玩家认可的版本留着。
3. blueprints render 画出来看：上面两张斜 45° 立体图，下面每层平面图，还有文字平面图。第一版一般都有毛病：按「看图检查」逐条挑，用 edit 改几处、或者改设计重新 save，再画，直到挑不出明显的毛病。
4. 图只有你看得到，玩家看不到：用几句话跟玩家说外观、大小、要备的料，玩家同意再盖。
5. build 带 blueprint 先 dryRun 看缺什么料，备齐再盖。一次最多 4096 格，大房子分几次。

## 零件

build 和 blueprints save/render 都收 shapes（按顺序，后面的盖掉前面同一格）、blocks 和 palette。坐标是绝对坐标（save 后存成相对最小角）。

- palette：按用途起名字的材料表，比如 {"frame":"spruce_log","wall":"oak_planks","roof":"dark_oak_stairs"}；任何写方块的地方写 "@wall"，也可以加属性 "@frame[axis=x]"。换风格只要换材料表。
- fill／hollow／walls：from 到 to 的实心块、空心盒、四面墙。line：一条线，原木、柱子类会顺着线的方向放。
- box：一个体块。from/to 是外框，四周是 block 的墙；floor 填最底层里面，ceiling 填最顶层里面；frame 给了就在最底层和最顶层加一圈横梁、四角和每 pillarEvery 格加竖柱（原木自动朝向）。
- window：墙上的窗洞。from/to 在同一面墙上（朝南北的窗 z 相同，朝东西的 x 相同），facing 是窗朝外的方向，block 是玻璃（也可以是栅栏、铁栏杆做格栅）。recess:true 玻璃往里退一格，窗洞更有深度；sill 是窗下面外侧的窗台（楼梯会倒放贴墙，台阶放上半）；trim 是窗四周一圈框。
- door：门洞，一格或两格宽（两格是双开门，铰链在外侧），facing 朝外，block 写门（spruce_door）。门上面那格自动空出来给门的上半，门洞再高的部分留空；trim 是门框。
- stairs：室内楼梯，facing 是往上走的方向，from/to 是第一级和最后一级（每往前一格升一格），宽度是另一个方向的范围；每级上面自动空出两格（会在上一层楼板上开出楼梯洞），support 给了就把每级下面填实。
- roof：屋顶。from/to 是屋顶最底一层：放在墙顶再上一层，长边两侧各宽出一格做屋檐，两端和墙齐平（山墙正好砌在端墙上）；宽出更多格就是更深的屋檐。style 是 gable（双坡，默认，两端是山墙，gableBlock 默认同材料的完整方块，"none" 不要山墙）或 hip（四坡，没有山墙）。pitch 1（默认）用楼梯，每格升一格；pitch 0.5 用台阶，每格升半格，屋顶平缓（日式常用）。屋脊默认用台阶，ridgeBlock 可以换。trim 是收边：写另一种楼梯，屋檐那一圈和两端山墙边（四坡是屋檐和四条斜脊）换成它。rings 只铺外面几圈（没有屋脊和山墙）：两层之间的腰檐、陡屋顶下面再加的一圈缓檐都用它。
- 平顶没有专门的零件：fill 一层做屋面，再 walls 一圈高一格做女儿墙。

一个 13×9 的木屋（正门朝北，外面一圈石砖小路）：

```json
{"palette":{"frame":"spruce_log","wall":"oak_planks","floor":"spruce_planks","roof":"dark_oak_stairs","edge":"stone_brick_stairs","base":"stone_bricks","glass":"glass_pane"},
 "shapes":[
  {"shape":"fill","from":{"x":-1,"y":0,"z":-1},"to":{"x":13,"y":0,"z":9},"block":"@base"},
  {"shape":"box","from":{"x":0,"y":0,"z":0},"to":{"x":12,"y":4,"z":8},"block":"@wall","frame":"@frame","floor":"@floor","pillarEvery":4},
  {"shape":"door","from":{"x":6,"y":1,"z":0},"to":{"x":6,"y":2,"z":0},"block":"spruce_door","facing":"north"},
  {"shape":"window","from":{"x":1,"y":2,"z":8},"to":{"x":3,"y":3,"z":8},"block":"@glass","facing":"south","recess":true,"sill":"spruce_stairs"},
  {"shape":"window","from":{"x":9,"y":2,"z":8},"to":{"x":11,"y":3,"z":8},"block":"@glass","facing":"south","recess":true,"sill":"spruce_stairs"},
  {"shape":"roof","from":{"x":0,"y":5,"z":-1},"to":{"x":12,"y":5,"z":9},"block":"@roof","trim":"@edge"}],
 "blocks":[{"x":6,"y":0,"z":-1,"block":"spruce_stairs[facing=south]"}]}
```

y=0 是地面上第一层：地板在 y=0，屋里能站的是 y=1～3，门口外面放一级楼梯上来。

## 通用手法

下面的数字是从 12 个玩家作品（小木屋、农舍、石屋、日式寺院、拉面馆、酒馆、现代别墅等）量出来的。

- 体块：先定 1～3 个长方体，一主一次；L 形、T 形、主屋加侧翼、两个双坡屋顶十字交叉都比一个方盒子好看。二层可以比一层外挑或内收一格。
- 比例：每层从地板到上一层楼板 4～5 格（屋里净高 3～4 格）；屋顶高度大约是总高的三分之一到一半；太长的墙用柱子或体块分段。
- 地台：作品几乎都不直接贴着草地，四周有一圈 1～2 格宽的石砖、圆石或平滑石小路或地台；寺院这类建筑坐在 1～3 格高的石台上，前面有台阶。
- 屋檐：住宅一般外伸 1～2 格；寺院、拉面馆这类 3～5 格。屋檐太深会盖住墙，房子像戴了个大盖子。
- 屋顶收边：屋顶边缘和屋脊几乎都换一种颜色——木屋顶配石砖边，深色瓦配木头边或白色屋脊；用 roof 的 trim 和 ridgeBlock。
- 柱子：原木柱每 4～6 格一根，从地台立到屋檐；楼层线压一圈横梁（box 的 frame）。
- 墙面层次：每面外墙都有 3 层以上前后变化（柱子凸出、窗退进去、窗台、门廊、檐下）；外墙表面三到四成是楼梯、台阶、活板门、栅栏这些不满格的方块，大片平墙一个都没有。
- 材料：墙最多的那种方块一般只占外墙的两到三成，其余是柱子、地基、窗、细节，按位置分工：地基（圆石、石砖）→ 墙（木板、陶瓦、羊毛、混凝土）→ 框架（原木柱、横梁）→ 屋顶（深色楼梯或台阶）→ 收边。小房子 8～20 种方块，细节多的 35～70 种；颜色深浅搭配，不要两种很冲的颜色硬碰。
- 质感：大面积的主材可以混 2～3 种相近的方块（石砖、裂纹石砖、苔石砖），看起来有年代感；混的时候成片、不要每格乱撒。
- 窗：外墙里玻璃一般占 5～17%（日式几乎不用玻璃，用格栅；石屋、现代 20～30%）。窗成组、有节奏，上下层对齐；玻璃板比玻璃块细致。正门要显眼：门两边放灯或柱子，上面有雨棚或横梁，门口有台阶。
- 细节：栅栏做栏杆和支架；灯笼挂在檐下或立在柱子上；树叶做花槽和灌木（放下去的树叶不会掉）；花、小路、篱笆、菜地收尾；烟囱高出屋脊一两格。开着的活板门（百叶窗）现在盖不出来，别用。
- 室内：每个房间有光源；楼梯上面留两格；床、工作台、箱子靠墙。
- 生存模式：木头、石头、玻璃好拿；羊毛、混凝土、石英、深板岩、下界材料要玩家准备，设计前问一句。复杂的屋顶（翘角、曲面）build 可能放不准，先用 roof 零件能盖出来的样子。

## 看图检查

- 比例：太扁、太高、屋顶太小？从远处看轮廓有没有主次。
- 平墙：有没有超过 5×5 一成不变的墙面；柱子、横梁、窗台有没有。
- 窗：节奏乱不乱、上下对不对得齐、一面墙是不是没有窗。
- 颜色：是不是太杂，或者对比太硬；屋顶有没有收边。
- 屋顶：边缘和屋脊整不整齐，有没有漏洞，山墙有没有补上；屋顶和屋檐是不是太大，盖住了二楼的墙、比墙还显眼。
- 落地：房子四周有没有小路或地台，门口有没有台阶。
- 能不能住：门口能不能走进去，楼梯净空够不够，每层有没有灯。
- 文字平面图里 # 是墙、W 是窗、D 是门、/ 是楼梯，用来核对坐标。

## 风格：日式

参考：日式寺院（Babadoozi）、拉面馆（MassiveSpeck）、千与千寻小屋（SheraNom）。
- 材料表：{"frame":"stripped_spruce_log","wall":"white_concrete_powder","base":"stone_bricks","roof":"deepslate_tile_stairs","edge":"dark_oak_stairs"}。墙也可以是平滑石英、方解石、白色羊毛；屋顶也可以是黑石砖的楼梯台阶，或者竹板台阶（茅草感，千与千寻小屋）；寺院屋顶深色、屋脊和斜脊用白色（石英、闪长岩）。
- 住宅的形体：屋顶用 gable、pitch 1，出檐 1 格，深色木收边；墙要露出来，屋顶和屋檐不能抢过墙。两层的做成上下分开的两段：二楼楼板那一层加一圈腰檐（roof 用 rings 1～2、pitch 0.5），一楼、二楼的墙各自露出来，二楼可以比一楼每边内收一格；也可以做成一个整体的两层，屋檐一样只伸 1 格。前面加一段带栏杆的木回廊，坐在一圈石砖台基上。试过的设计里，上下分开、屋顶不大的最受喜欢；屋檐伸 3 格、再叠两重大檐的像个大盖子，盖住了二楼，不受喜欢。
- 寺院、店铺的形体：屋顶高度接近总高一半，檐口外伸 3～4 格。屋顶分两段：主屋顶 hip（寺院）或 gable，pitch 1，比墙每边宽 1 格；下面低一层再叠一圈 hip、pitch 0.5、rings 2 的缓檐，比主屋顶每边再宽 2 格。只用 pitch 0.5 盖 13 格宽以上的屋顶会又扁又大。寺院坐在 2～3 层的石台上（石砖混裂纹、苔石砖），正面一段石阶；外面一圈木回廊：地板高出地面一格，边上栅栏做栏杆。
- 窗：几乎不用玻璃（寺院 1%，拉面馆 0%）：窗洞里放深色木栅栏或竹子做格栅，或者玻璃板配深色木框（window 的 trim）。
- 细节：檐下挂灯笼；门前石灯笼（石砖墙上放灯笼）；红色柱子加深色横梁的鸟居；樱花树叶、竹子、粉红花簇；店铺门口用红白相间的羊毛做布棚，挂告示牌当招牌。
- 生存：深板岩瓦要去很深的地方挖，混凝土粉末要沙子、沙砾和染料，竹子和樱花只在特定群系。

## 风格：乡村木屋

参考：小木屋第二弹、花园生存农舍、石屋_三。
- 材料表：{"frame":"oak_log","wall":"spruce_planks","base":"stone_bricks","roof":"spruce_stairs","edge":"stone_brick_stairs","glass":"glass_pane"}。框架也常用去皮原木，两种原木（云杉、白桦）分别做柱和横梁；屋顶也可以整个用石砖楼梯（石屋）。
- 形体：一到两层，层高 4～5；双坡 pitch 1，出檐 1～2 格；主屋加侧翼成 L 形或两个双坡十字交叉；原木柱每 4～6 格（box 的 pillarEvery），比墙面凸出更好看（柱子单独用 line 立在墙外一格）。
- 窗：外墙玻璃 8～17%，玻璃板，下面窗台（sill 用楼梯）和花槽（树叶，前面挡一排活板门）。
- 细节：门廊（原木柱、栅栏栏杆、木板地面）；圆石或石砖烟囱；屋顶上的小老虎窗；四周篱笆、菜地、石子小路，柱子上挂灯笼。
- 生存：全是好拿的材料，最适合生存早期。

## 风格：石砖小屋

参考：小房屋第四弹（17×15，997 格，只用 8 种方块）。
- 材料表：{"wall":"stone_bricks","roof":"smooth_stone_slab","edge":"stone_brick_stairs","glass":"glass_pane","base":"stone_bricks"}。
- 形体：一层，方正；墙底下一圈高一格的石砖台阶做墙裙，墙裙外是一排树叶花槽；窗与窗之间是凸出一格的石砖壁柱。屋顶 gable、pitch 0.5，屋面两种台阶（平滑石台阶、石砖台阶）一条一条交替；出檐 1～2 格。
- 窗：大窗，外墙玻璃约三成：每两根壁柱之间一个 2～3 格宽、2～3 格高的玻璃板窗。
- 细节：门前两三级平滑石台阶，门两侧火把或灯笼。材料少、好拿，靠形体和节奏好看。

## 风格：现代

参考：泳池小院别墅、以前做过的现代平顶别墅。
- 材料表：{"wall":"white_concrete","band":"light_gray_concrete","dark":"gray_concrete","glass":"white_stained_glass_pane","wood":"birch_planks"}。
- 形体：两三个长方体错开叠放，平顶（fill 屋面，walls 一圈浅灰女儿墙），屋顶可以开一片玻璃天窗；用一圈深色（灰或黑混凝土）的框把其中一个体块包起来；木平台、露台、泳池庭院，四周一圈树叶绿篱。
- 窗：外墙玻璃约两成：通长的横向窗带或落地窗，窗框细。
- 细节：末地烛、海晶灯做灯；石英楼梯做台阶；遮阳伞、躺椅。深色要用有纹理的材料（深板岩、木头），不要纯黑和纯白硬碰。
- 生存：混凝土要沙子、沙砾和染料，量很大，先问玩家；泳池的水 build 放不了，盖好后玩家自己倒。

## 风格：西部酒馆

参考：沙龙酒馆（20×20，两层）。
- 材料表：{"frame":"oak_log","wall":"spruce_planks","accent":"birch_planks","roof":"oak_slab","glass":"glass_pane"}。
- 形体：两层，层高 5；平顶（台阶铺屋面），临街一面的墙高出屋顶、中间做成阶梯状的假门脸；一层门廊绕两面，原木柱撑着二层的阳台，阳台和门廊边上都是栅栏栏杆；转角原木柱凸出墙面。
- 窗：外墙玻璃约 8%，窗上面用台阶搭在栅栏上做小雨棚。
- 细节：栅栏门做弹簧门，台阶和活板门做吧台，酿造台、炼药锅、木桶当摆设。

## 风格：木构大厅

参考：大型公会仓库（Eileen_chun，21×28×59，近一万格，要分三次 build）。
- 材料表：{"frame":"stripped_spruce_log","wall":"spruce_planks","roof":"spruce_stairs","edge":"andesite_stairs","base":"stone_bricks"}。
- 形体：又长又窄的大厅，陡的双坡（pitch 1）占总高一半以上；中间横插一个更高的十字山墙，山墙面开彩色玻璃大窗；一层层高 7，往上 5；整栋坐在一圈石砖地台上。
- 立面：去皮原木柱每 4 格一根，柱间是木板墙，用楼梯和活板门在墙上拼出花纹；屋檐和山墙边一律灰色收边。

## 风格：集市小摊

参考：肉铺（10×5×6，180 格）。
- 材料表：{"post":"deepslate_brick_wall","counter":"mud_brick_stairs","awning":"yellow_wool","awning2":"white_wool","edge":"spruce_trapdoor"}。
- 形体：一格高的柜台（楼梯倒放）加两三根柱子，顶上一片条纹布棚（两色羊毛相间，边上一圈活板门），没有墙。
- 细节：木桶、饰纹陶罐、营火、栅栏做挂架；整个摊位一大半是摆设，几十格就能很好看。

## 风格：庭院和大树

参考：池塘樱花树、花园生存农舍的菜园。
- 大树：树干用原木或木头方块（spruce_wood），粗 2～3 格，往上分几根斜枝；树冠是不规则的几团，宽度是高度的 2～3 倍，用树叶或者同色系的羊毛加染色玻璃做半透明感；树冠下用锁链挂灯笼。
- 地面：草方块、砂土、苔藓块、石子路（安山岩、沙砾）成片混着铺，不要整齐划一；竹子、花、草点缀；池塘和水渠的水要玩家自己倒。
- 菜园：一垄一垄的耕地，中间留水渠，四周栅栏，路口栅栏门。
